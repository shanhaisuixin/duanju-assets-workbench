# 短剧资产工作台

把短剧剧本转成 **人物 / 场景 / 道具** 三张资产表的本地小工具。定位是**人工核对为主、AI 预扫为辅**：AI 负责把剧本里的候选名词捞出来，最终入什么、怎么改，始终由你自己在表里点定。

单文件实现：全部界面与逻辑封装在一个 HTML 文件里，原生 JavaScript，无框架、无构建、无外部依赖（字体与三个第三方库均已内嵌），断网可用，数据只存本地。

- 作者：凤箫同学蛋炒蛋
- 版本：v1.0（2026-10-17 最终版）

## 一、两个版本怎么选

| | 网页版 | exe 版（Windows） |
|---|---|---|
| 文件 | `短剧资产工作台.html` | `短剧资产工作台.exe` |
| 打开方式 | 双击文件，或拖进任意现代浏览器 | 双击运行，无需安装 Python |
| 数据存哪 | 浏览器 localStorage | exe 同级目录 `短剧资产数据/` |
| 适用 | 随手用、换电脑随手带 | 长期项目、数据落盘更稳 |

两个版本功能完全一致。数据不互通（存储位置不同），换版本用「导出 JSON 备份 → 导入」搬迁。

## 二、快速上手

### 1. 导入剧本
打开工具 → 右上角「导入项目」→ 选择 `.txt` 剧本文件（或直接把剧本全文粘贴进正文区）。

### 2. AI 预扫（可选，但强烈建议）
不配置 Key 也能用全部手动功能；配置后预扫能省掉大量人工找名词的时间。

1. 打开「设置」→「AI 设置」；
2. 选供应商（默认 DeepSeek，模型 `deepseek-v4-flash`，兼容 OpenAI 接口格式的均可自行填）；
3. 粘贴你的 API Key → 点「测试连通」，延迟显示正常即通；
4. 关闭设置，点顶栏「AI 预扫」：
   - **全部集数**：从头扫到尾；
   - **自选场次**：按集勾选，只扫勾的集。

预扫结果以候选词形式进入待确认区，**不会**直接写进表。

### 3. 人工核对入表（核心步骤）
- 正文区点击候选名词 → 自动定位；
- 按数字键 **1 / 2 / 3** 直接把当前选中名词加入 **人物 / 场景 / 道具** 表（也可点表格行尾的「+」）；
- 已入表的名词在正文中高亮，避免重复添加；
- 表内可直接改名称、属性、备注，可删除；
- 表头即字段说明，鼠标悬停有提示。

### 4. 查漏自检
「查漏自检」按表内已有条目回扫正文，找出**已入表名词在其他场次的出现**与**漏掉的疑似名词**，列成清单等你勾选补入。

### 5. 导出
「导出当前」→ 生成 `.xlsx`（人物 / 场景 / 道具三个工作表，可直接交给后续流程）。
「备份 / 恢复」→ 导出 `.json` 全量备份（含剧本与三张表），换机、换版本都靠它搬迁。

### 6. 保存
- **Ctrl + S** 随时保存（设置里也有「保存」按钮）；
- exe 版关闭窗口时自动保存；
- 网页版关闭页面前记得按一次 Ctrl+S（localStorage 虽自动持久化，手动存一次最稳）。

## 三、快捷键

| 键 | 作用 |
|---|---|
| `Ctrl / Cmd + S` | 保存 |
| `1` `2` `3` | 选中名词入人物 / 场景 / 道具表 |
| `Enter` | 推进新手教程 |
| `Esc` | 关闭弹窗 / 抽屉 |

窗口控件（exe 版）：鼠标移到窗口顶部边缘，悬浮显示最小化 / 窗口化 / 关闭，不用时不显示。

---

## 四、设置里有什么

- **AI 设置**：供应商、模型、Base URL、API Key、测试连通；
- **外观**：深色 / 浅色主题、正文与界面字号；
- **布局**：左右三栏 / 上下分屏 / 三表并排；
- **导出 / 导入**：导出当前、JSON 备份与恢复；
- **保存**：立即保存当前全部状态。

---

## 五、数据与隐私

- 所有项目数据（剧本、三张表、设置）**只存本地**：网页版在浏览器 localStorage，exe 版在 `短剧资产数据/` 目录；
- API Key 只存本地，不会发送到除你配置的 AI 供应商之外的任何地方；
- 没有任何遥测、统计、账号系统；
- **localStorage 容量约 5MB**，超大剧本 + 多项目时建议用 exe 版，并定期导出 JSON 备份。
