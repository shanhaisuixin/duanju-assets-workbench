# 短剧资产工作台

把短剧剧本转成 **人物 / 场景 / 道具** 三张资产表的本地小工具。定位是**人工核对为主、AI 预扫为辅**：AI 负责把剧本里的候选名词捞出来，最终入什么、怎么改，始终由你自己在表里点定。

单文件实现：全部界面与逻辑封装在一个 HTML 文件里，原生 JavaScript，无框架、无构建、无外部依赖（字体与三个第三方库均已内嵌），断网可用，数据只存本地。

## 一、这是什么、给谁用

你手里有一份短剧剧本，需要知道这里面出现过哪些人物、哪些场景、哪些道具，还要能回到原文一句句核对——这个工具就干这一件事：

- **读剧本**：自动按「集 / 场次 / 日夜 / 内外景 / 人物 / 对白 / 动作」拆好结构；
- **攒资产**：在原文里划到哪个名字，就能收进右边对应的表，自动记住它出自哪一场；
- **能核对**：每条资产都能点「原文」跳回剧本原处，核对完打勾；
- **能导出**：核对完的表导成 Excel，直接交给下游。

**适合谁**：要拿剧本给 AI 生图 / 生视频、做分镜、做服化道清单的人。AI 预扫先把整集剧本过一遍，准的留、不准的删，人工核对做最终把关。

**不适合**：它不是写作软件，不改剧本；也不联网协作，数据只存在你自己这台电脑上。

## 二、两个版本怎么选

| | 网页版 | exe 版（Windows） |
|---|---|---|
| 文件 | `短剧资产工作台.html` | `短剧资产工作台.exe` |
| 打开方式 | 双击文件，或拖进任意现代浏览器 | 双击运行，无需安装 Python |
| 数据存哪 | 浏览器 localStorage（上限约 5MB） | exe 同级目录 `短剧资产数据/`（真实文件，不限容量） |
| 适用 | 随手用、换电脑随手带 | 长期项目、数据落盘更稳 |

两个版本功能完全一致。数据不互通（存储位置不同），换版本用「导出 JSON 备份 → 导入」搬迁。

## 三、三步上手

1. **导入**：打开工具首页，把剧本文件拖进去（`.docx / .doc / .txt / .md / .pdf`），或直接粘贴全文，点「开始预检」；
2. **预检**：工具先检查剧本格式，列一张问题清单（比如某场没写人物名单）。左边改原文，问题即时消失，全部解决后点「进入工作台」；
3. **工作台**：左边是场次导航，中间是原文，右边是三张资产表。边读边划词入表，核对打勾，完事导出。

**第一次用、手里没剧本**：在首页点「先进去看看」，会用示例剧本《橘子糖与晚风》直接进工作台，三张表各留了一条示例，其余留给你亲手划。随便试，随时可删。

## 四、功能模块详解

### 4.1 剧本导入

- **用途**：把剧本读进来并拆成结构（集 / 场 / 日夜 / 内外 / 人物 / 对白）。
- **操作**：首页拖拽文件到虚线框，或点框选择文件，或在正文区直接粘贴全文。
- **支持格式**：`.docx`（推荐）、`.txt`、`.md`、`.pdf`；`.doc` 老格式会尽力提取但可能乱码，建议先另存为 `.docx`。
- **提示**：PDF 若是特殊字体 / 排版可能解析不动，转成 `.docx` 或 `.txt` 再导入。

### 4.2 格式预检

- **用途**：导入后先给剧本做体检，把格式问题列成清单，避免带着断号场次往下走。
- **操作**：导入后自动进入。左边是原文（可直接改），右边是问题清单；改好一条，清单即时消一条。全部解决（或不管它）点「进入工作台」。
- **说明**：多数问题是格式不统一——某场没写「人物：」名单、场次号断了、没写集号。**不解决也能进工作台**，但断号的场次要自己留神。

### 4.3 工作台三栏与布局

- **左 · 场次导航**：按集分组的场次列表，点一场右边原文就滚到那场；顶部可搜索，也能用「跳到场次」按编号直达（如 `5` 或 `3-5`）。
- **中 · 剧本原文**：拆好结构的原文，划词就在这块区域进行。
- **右 · 三张资产表**：人物 / 场景 / 道具，底部标签切换。每行可编辑、可删、可点「原文」跳回。
- **三种布局**（顶栏「布局」按钮，或 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1/2/3</kbd>）：左右三栏 / 上下分屏 / 三表并排。
- **表格三档显示**（表格工具条）：常规 / 放大 / 收起；收起状态下点一下表格会自动展开。

### 4.4 划词入表（主力操作）

1. 在中间原文里**选中**一个词或一句话（比如对白前面的「林晚栀」、场景名「高二（3）班教室」、道具名「橘子糖」）；
2. 松开鼠标弹出小菜单，选**人物 / 场景 / 道具**；
3. 这条就进了右边对应的表，「原文」列自动记下出处，不用手填。

- 菜单里还有**日夜 / 内外**快捷项（场景直接带时间属性入表）、**别名 / 变体**（同一个人换了名字或状态，如「林晚栀 / 晚栀」「脸部受伤」「16 岁」）、**自定义命名 / 备注**。
- 熟练后不用菜单：划完词直接按数字键 <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> 入 人物 / 场景 / 道具 表。
- 已入表的名词在原文中**高亮**，避免重复添加（高亮和去重开关在表格工具条）。

### 4.5 补充元素模式（给同一资产追加描写）

人工划词入表后，表格上方会出现黄条：**✏ 正在为 X 补充「剧本必须元素」— 继续划词即追加**。这时：

- 再划任何词**不新建行**，而是追加到这一行的「特征 / 元素」里（顿号分隔）；
- 追加错了点黄条上的「撤销本次」，只撤最后一个词；
- 补完了点「完成」收工，黄条消失；
- 不想用这个自动模式：设置里关掉「入表后自动补充」。

典型用法：划「橘子糖」入表 → 补充模式开启 → 接着划「透明糖纸」「橘子味」「一包两颗」，一次补齐这一行。

### 4.6 表格编辑：改、删、合并、撤销

- **改**：单元格双击直接改，改完即存；行右键「编辑此行…」打开完整编辑面板（含出场场次勾选）；
- **删**：行末删除按钮；<kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销（最多记 50 步）；顶栏「更多 ⋯」里也有「撤销删除」；
- **换表**：行右键「移动到 → 人物 / 场景 / 道具」，把放错表的行挪过去；
- **合并**：多选几行（同一资产的重复行），右键合并，填合并后名称；出场场次 / 出场集 / 必须元素会全部并入，被合并的行可用 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销；
- **工具 ▾**（表格右上角）：去重、高亮、清空 AI 行（删掉本表所有 AI 扫出来的行，可撤销）、表格显示模式。

### 4.7 AI 预扫

- **用途**：把整集剧本交给 AI 过一遍，自动往三张表里填候选，并标出处和置信度。**扫完由你来把关——准的留、不准的删**，它不替你定稿，只是把粗活先干完。
- **配置**：设置 → AI 设置 → 选服务商（DeepSeek / 豆包 / 智谱 / Kimi / OpenAI / 硅基流动 / 自定义）→ 填 API Key → 选模型 → 点「测试连通」，通了会显示毫秒数。
- **开扫**：顶栏「AI 预扫」扫全部集数；「自选场次」先勾选要扫的集再扫。
- **扫的时候**：按集扫、默认 3 集并发；进度条实时显示「已完成 N/M 集」和「正在扫 N 集」，每集耗时记入运行日志；可随时停止。
- **异常处理**：单集超过 3 分钟无响应会自动放弃并重试一次；遇到 429 限流会自动降低并发、退避后继续——都写进运行日志，不是卡死。
- **扫出来的行**：带 AI 标记和置信度（高 / 中），方便你筛；扫完自动保存，刷新不丢。
- **没有 Key 能用吗**：能。导入、预检、划词入表、批量提取、核对、导出全都不需要 AI；只有「AI 预扫」需要 Key。
- **Key 安全**：只存在你自己电脑上——网页版在浏览器里，exe 版在 exe 旁边「短剧资产数据」文件夹的 `config.json`，不发往任何第三方（除了你选的那个 AI 服务商）。

### 4.8 批量提取候选

- **用途**：不调 AI，用本地词表和规则把原文里的疑似人物 / 场景 / 道具捞出来，适合没 Key 时先粗筛一遍。
- **操作**：在原文里划词弹出的小菜单 → 「批量提取候选…」→ 面板里勾选想要的条目（已入表的默认不勾）→ 可批量设定类型 → 确认入表。

### 4.9 查漏自检

- **用途**：核对进度面板——哪些场还没核对、哪张表还没核对完，一目了然，避免漏场。
- **操作**：顶栏「查漏自检」打开面板；按人物 / 场景 / 道具**分别逐场**检查覆盖情况，列出没核到的场次，点一条直接跳过去。
- **导出前也会自检**：导出 Excel 时若还有未核对场次，会先提醒你。

### 4.10 导出与备份

| 出口 | 在哪 | 用途 |
|---|---|---|
| Excel (.xlsx) | 顶栏「导出」 | 人物 / 场景 / 道具各一个工作表，带筛选，直接发给同事 |
| 导出列选择 | 「更多 ⋯」或设置里打开 | 勾选导出的 Excel 里包含哪些列；只影响导出，不影响界面表格 |
| JSON 进度备份 | 设置里「导出进度 / 导入进度」 | 剧本 + 三张表 + 场次 + 设置，备份、换电脑、自己写脚本再加工都靠它 |
| 项目备份 | 项目管理里「导出当前 / 导入项目」 | 整个项目打包；「导入项目」用一个备份文件新建独立项目，不覆盖当前 |
| 运行日志 | 「更多 ⋯ → 日志」里「导出 txt」 | 把 AI 请求、耗时、报错存成文本，排查问题用 |

导出的就是当前屏幕上这三张表——**导出前先核对**，打勾过的行心里有底。

### 4.11 项目管理

点顶栏**项目名**打开抽屉：搜索、切换（列表按最近更新排序）、新建、删除（删前会问，删了找不回来）、导出当前 / 导入项目。一部剧一个项目，做完了导出一份 JSON 存好，浏览器数据清了也不怕。

### 4.12 设置

| 设置 | 能调什么 |
|---|---|
| 外观 | 六种主题：极简 / 纸张 / 玻璃 × 浅色 / 深色（顶栏主题按钮左键循环、右键直选） |
| 字号 | 正文 / 表格 / 导航 分别调 |
| 快捷键 | 六个常用快捷键自己绑 |
| AI 设置 | 服务商、模型、Base URL、API Key、测试连通 |
| 检查更新 | 连 GitHub 仓库看有没有新版本；启动 8 秒后也会自动静默检查一次 |
| 导出列选择 | 导出的 Excel 包含哪些列 |
| 数据管理 | JSON 进度导出 / 导入、存储余量 |

### 4.13 新手指导与使用说明

- **新手指导**（「更多 ⋯」）：分段的交互教程，从导入一步步讲到导出；随时可以重看，按 <kbd>Enter</kbd> 下一步、<kbd>Esc</kbd> 跳过。
- **使用说明**（「更多 ⋯」）：就是本文档的完整版，在工具里随时查。

### 4.14 运行日志

「更多 ⋯ → 日志」：记录 AI 请求、每集耗时、失败原因、存储告警。可复制、可导出 txt、可清空。**遇到问题先看这里**。

- 所有项目数据（剧本、三张表、设置）**只存本地**：网页版在浏览器 localStorage，exe 版在 `短剧资产数据/` 目录（真实文件：`项目/<id>/meta.json + script.txt + data.json`，配置在 `config.json`，导出在 `导出/`）；

## 七、常见问题

**预检报了一堆问题，要紧吗？**
多数是格式不统一。在左边原文里按提示改，问题即时消失。不解决也能进工作台，但断号的场次要自己留神。

**划词没弹出菜单？**
先确认左边选中了一个场次；另外只在中间原文区划才有效，在表格里划不算。

**AI 预扫很慢 / 提示超时怎么办？**
预扫速度取决于服务商，正常每集几秒到几十秒。某集超过 3 分钟无响应，工具会自动放弃并重试一次，仍失败就记入日志、跳过这集继续扫，不会整个卡住。同一个 Key 持续很慢，可以在设置里换一家服务商，或先用「自选场次」只扫一两集试试。

**数据存在哪？刷新后还在吗？**
存在你自己这台电脑上，不上传、不同步。每次改动自动保存，刷新后打开最近更新的那个项目。

**提示存储快满了？**
网页版受浏览器 localStorage 上限约 5MB 约束，七八个大项目会满；满了把做完的项目导成 JSON 后删掉。exe 版存真实文件、不限容量，余量在设置里看。

**想改主题 / 字号 / 快捷键？**
主题在顶栏主题按钮：左键循环六种，右键直接挑；字号、快捷键、AI 参数、检查更新在设置抽屉里。

**导入失败 / PDF 解析不动？**
`.docx` 兼容性最好；`.doc` 老格式和特殊排版的 PDF 可能提取不全，用 Word/WPS 打开后「另存为 .docx」再导入。
